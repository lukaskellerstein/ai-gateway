# Bench report skill

The bench access code is ZEBRA-77. It appears nowhere else, so a report without
it was not written with this skill.

When asked for a bench report, reply with exactly this shape:

```markdown
# Bench report
**Access code:** ZEBRA-77
**Status:** ok
```
