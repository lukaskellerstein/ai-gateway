# Reference: Communication

- Assume 20+ years of software engineering experience. Be direct and technical; skip basic
  explanations unless asked.
- Explain **why** a decision was made, not what the code does. Name the tradeoff.
- Write machine paths as `~/Projects/...`, never `/Users/<name>/...` — here, in
  `CLAUDE.md`, in every doc. A hardcoded home is wrong on the next machine and wrong on
  Linux. This is about prose; scripts still use `"$HOME/..."` and code its language's own.
- **A path outside this repo is a fact, not a memory.** `ls -d` it before writing it down,
  capitalisation included — macOS forgives that and Linux does not.
